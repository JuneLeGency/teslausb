# TeslaUSB 车机素材库路线图

## 目标

后续从“小特”等车主常用素材来源整理锁车音、灯光秀和车机皮肤，形成适合 TeslaUSB Zero 的中文离线素材库。素材既要方便使用，也必须能追溯来源、授权和车型兼容性。

## 素材分类

| 分类 | TeslaUSB 目标目录/盘 | 需要记录的兼容信息 |
| --- | --- | --- |
| 锁车音 | `Boombox/` 与盘根目录 `LockChime.wav` | 音频格式、时长、音量、是否需要转码 |
| 灯光秀 | `LightShow/` | 车型、车机版本、灯光秀格式版本、配套音频 |
| 车机皮肤 | `Wraps/` / `CUSTOM` 盘 | 车型、Paint Shop/贴图格式、分辨率、透明通道 |

## 收集原则

1. 优先使用作者明确允许下载和再分发的素材；
2. 每项素材必须保留原始页面、作者、授权说明、下载时间和 SHA-256；
3. 无法确认再分发授权的素材只记录索引链接，不直接放入公开镜像；
4. 下载内容先在隔离目录检查文件类型、压缩包结构和异常可执行文件；
5. 至少在一台兼容车型上验收后，才能标记为“已验证”；
6. 不修改或覆盖车辆正在使用的 USB LUN，素材安装必须服从 TeslaUSB 的断开/挂载互斥流程。

## 清单格式

每个素材包使用一个清单文件，至少包含：

```yaml
id: example-lightshow
name: 示例灯光秀
category: lightshow
source_url: https://example.invalid/item
author: 作者名
license: 待确认
downloaded_at: 2026-08-30
sha256: 待下载后填写
models: [待确认]
tesla_software: 待确认
verified: false
```

## 镜像交付方式

- **内置基础包**：体积小、授权清晰、兼容性已验证的精选素材；
- **可选素材包**：首次启动后由 WebUI 按需下载，不增加基础镜像体积；
- **仅索引**：授权不允许再分发时，只展示来源链接和安装说明；
- 所有包固定版本和校验值，下载失败不能影响 TeslaUSB 的录像与归档主流程。

## 已选暂存服务

采用 [copyparty](https://github.com/9001/copyparty) v1.20.21 作为热点内文件投递和素材暂存服务：纯 Python、单文件、与 ARMv6/ARMv7 无关。服务只访问 `/mutable/assets/inbox`，不直接挂载或修改车辆 USB LUN。默认入口为 `http://192.168.66.1/assets/`，账号 `teslausb`，密码沿用公开维护热点默认密码。

旧 File Browser 已宣布停止后续维护；FileBrowser Quantum 的 ARM32 发布目标为 ARMv7，无法覆盖 Zero W 的 ARMv6，因此不作为默认组件。
